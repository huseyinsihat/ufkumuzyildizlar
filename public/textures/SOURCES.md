# Texture sources

Existing planet maps (`earth.jpg`, `mars.jpg`, and the other cylindrical JPGs) are NASA / USGS classroom maps already in this folder.

Moon maps (`io.jpg`, `europa.jpg`, `ganymede.jpg`, `callisto.jpg`, `titan.jpg`, `phobos.jpg`, `deimos.jpg`, `pluto.jpg`) should be equirectangular 1024–2048 px NASA / USGS products. Globe photographs stretch on the sphere.

Until those files are present, `loadBodyTextures` keeps the procedural canvas (Io sulfur, Europa ice, Titan haze, cratered rocky moons).

Do not commit 8K maps.
